Say: each layer has a job and a blind spot. We list the blind spots. The digit challenge stops a pre-generated clone but not a live voice changer or fast type-to-speech; layer 2 is the main defence there, with post-call review as the backstop. Fusion is a small rule set over scores calibrated with logistic (Platt) scaling on a dev split, not a black box. Thresholds are placeholders until validation: set them on held-out data, then freeze before the demo.

Say: this is what the agent and the customer would see. It is an illustrative screen, not a built product; the screens are part of the finale build. The agent sees a band and a plain message, never the raw score. Clear: no flag, no extra step. Step up: the agent reads six random digits to the customer; speech-to-text checks the answer and reply time. Hold: the request is paused, the message tells the agent to ask the customer to confirm in the app, and an analyst opens a case. Only Hold sends an app prompt; the customer can confirm, deny or report. The customer never learns which check fired or the score.

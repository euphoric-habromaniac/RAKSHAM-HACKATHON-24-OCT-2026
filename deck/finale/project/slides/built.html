What exists today. We recorded three consenting teammates reading 100 bank-call sentences in Hindi, English and Hinglish, cloned each voice with an open model (XTTS-v2), and added GSM and G.711 telephone copies. The detector is a small numpy model: it only judges windows that contain speech, decides every 0.25 s from the last 0.5 s, and runs in a browser with no GPU. The agent dashboard adds a random-phrase challenge, a spectrogram with the flagged stretches, and a case file saved with its audio. Say plainly that this is a feasibility build on three speakers. About 60 seconds.
